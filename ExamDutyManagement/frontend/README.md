# Exam Duty Management System - Frontend

Web application built with **React.js**, **TypeScript**, **Vite**, **React Router**, and **Axios**.

---

## Configuration (`.env`)

```env
VITE_API_URL=http://localhost:5000/api
```

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

The app will be available at `http://localhost:3000`.
